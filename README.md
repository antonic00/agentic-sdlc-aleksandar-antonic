# Agentic SDLC: Building a Software Factory

A hands-on course where you build an AI-powered software development lifecycle by creating specialized agents for each phase of the SDLC — from requirements and architecture through testing and deployment. By the end, you'll have a working "software factory": a suite of collaborating agents that can take a feature idea from concept to production.
